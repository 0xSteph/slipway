# Signing in

iPhones only run apps signed for them. xtool signs your app with your Apple ID, like Xcode does.

- You type your password and two-factor code into xtool in a terminal. Slipway never sees them.
- A free Apple ID works. Apps signed with one stay installed for 7 days; Slipway reminds you and reinstalls them in one click.
- If you can, use a secondary Apple ID.
